## What I'm Building

### SKLoud App

A civic-tech platform for Sangguniang Kabataan units in the Philippines, helping youth councils manage budgets, track projects, and stay compliant with government reporting.

### SKLoud Aurora

A DOST-PCIEERD-funded initiative under SKLoud App focused on blockchain-backed financial transparency for SK governance.

### Pulse

An open-source Bayanihan emergency response network for the Philippines. Pulse is designed to help people send emergency alerts to nearby responders, even in connectivity-limited situations where normal mobile data may not work.

### andri

An all-in-one LAN speed tester in a single Rust binary — measures TCP throughput, UDP packet loss and jitter, and real file-transfer speed, and isolates network-only performance from end-to-end file copy so you can tell whether a slow transfer is the wire or the disk.

### Open Source

I contribute to tools and libraries I use, and I keep a collection of public projects across web, mobile, systems, experiments, and learning work.
